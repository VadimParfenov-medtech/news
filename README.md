# GlobalNews — Новостной портал

Современный новостной портал с поддержкой перевода статей на 4 языка: Русский, English, Español, Deutsch.

## Особенности

- 🌍 **Мультиязычность** — переводите статьи прямо на странице
- 📰 **8 категорий** — Политика, Технологии, Экономика, Наука, Культура, Спорт, Здоровье, Экология
- ⚡ **Быстрая навигация** — мгновенная подгрузка контента
- 🎨 **Современный дизайн** — адаптивная верстка для всех устройств
- 📱 **Mobile-first** — оптимизировано для смартфонов и планшетов

## Структура проекта

```
news/
├── index.html          # Главная страница
├── article.html        # Шаблон страницы статьи
├── category.html       # Шаблон страницы категории
├── css/
│   └── style.css       # Стильный дизайн
├── js/
│   ├── i18n.js         # Система локализации
│   └── main.js         # Основная логика приложения
└── data/
    └── news.json       # Данные о новостях и категориях
```

## Как запустить

Просто откройте `index.html` в любом современном браузере:

```bash
# Windows PowerShell
Start-Process "index.html"

# Linux/macOS Terminal
open index.html  # macOS
xdg-open index.html  # Linux
```

Или используйте локальный сервер (рекомендуется):

```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve .
```

## Добавление новых статей

1. Откройте `data/news.json`
2. Добавьте объект статьи в массив `articles`:

```json
{
  "id": "9",
  "slug": "unique-slug-here",
  "title": {
    "ru": "Заголовок на русском",
    "en": "Title in English",
    "es": "Título en Español",
    "de": "Titel auf Deutsch"
  },
  "excerpt": { /* краткое описание */ },
  "content": { /* полная статья с HTML */ },
  "category": "technology",
  "date": "2025-12-20",
  "author": { "ru": "Имя автора" },
  "readTime": 5,
  "emoji": "📝",
  "translations": { "en": true, "es": true, "de": true }
}
```

## Технологии

- **Vanilla JavaScript** — нет внешних зависимостей
- **localStorage** — сохранение предпочтений пользователя
- **Intl API** — форматирование дат на разных языках
- **CSS Grid & Flexbox** — современная верстка
- **CSS Variables** — темизация через переменные
